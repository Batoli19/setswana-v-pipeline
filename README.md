# Setswana Voice Pipeline

A complete pipeline for scraping, processing audio, transcribing, and compiling Setswana voice datasets.

## Project Structure

This repository is structured as follows:

- **[`scraper/`](file:///c:/Users/user/Documents/BAC/setswana%20voicve%20%20pipeline/setswana-v-pipeline/scraper/)**: Pulls written text from sources such as BOPA and Daily News.
- **[`audio/`](file:///c:/Users/user/Documents/BAC/setswana%20voicve%20%20pipeline/setswana-v-pipeline/audio/)**: Contains scripts to process raw audio files.
- **[`transcription/`](file:///c:/Users/user/Documents/BAC/setswana%20voicve%20%20pipeline/setswana-v-pipeline/transcription/)**: Houses the transcription and correction web application.
- **[`datasets/`](file:///c:/Users/user/Documents/BAC/setswana%20voicve%20%20pipeline/setswana-v-pipeline/datasets/)**: Stores manifest files, metadata, and dataset configurations.
